# 光谱暗房 · 简洁抽象图标选型

> 项目现名为 **SpektraLens**（2026-11-05 起）。本目录的历史图片、生成提示词与交付文件名保留制作时的记录；后续项目展示使用新名称。

日期：2026-11-04。根据“更符合现在的设计审美、不那么具象、更简洁”的要求，制作四组方向。

| 编号 | 名称 | 设计方向 |
| --- | --- | --- |
| A | 负形 S | 以大色块和流动的负形保留 S 的联想，延续黑橙品牌色。 |
| B | 错位 | 两块错开的半圆构成光与影，黑、米白和橙色形成平衡。 |
| C | 叠光 | 两束橙色几何形相叠，暖白背景带来更轻柔的观感。 |
| D | 余光 | 开口圆环与小色块形成光线进入的抽象暗示。 |

四张原始图片均使用内置 `image_gen` 生成，完整提示词保存在 `generation-prompts.json`。每个方案目录下的 `source.png` 保留生成原图；`icon-1024.png` 为缩放导出，`preview-rounded.png`、`preview-circle.png` 和小尺寸 PNG 为遮罩与缩放预览。

`contact-sheet.png` 汇总四组方案、圆形预览及按原始像素排布的 64/48/32px 小图。聊天或图片查看器缩放整张对比图时，小图也会一起缩放；实际像素判断可打开各目录中对应的 PNG。

`export-previews.swift` 只负责缩放、应用预览遮罩和排版，没有重绘或修饰原始图案。在项目目录执行以下命令可重新导出：

```sh
swift design/app-icon/v2-concepts-2026-11-04/export-previews.swift
```

本轮交付为设计选型稿，保留现有应用资源及 APK。选定后再制作适合 Android 自适应图标的前景、背景和单色图层。
