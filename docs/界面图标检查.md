# v0.2.4 界面图标检查

本次检查覆盖首页、胶片、相纸、调色、裁切、片边/日期、模拟面板，以及相关选择和编辑弹窗。保留的图标均对应实际操作或状态。

| 位置 | 清理或保留依据 |
|---|---|
| 首页 | “试用示例”去除外跳箭头；“继续编辑”使用清楚的文字。关于入口改为“关于”，修正文字换行；移除动效开关，背景自动随前后台启停。 |
| 编辑器页头 | 返回首页与导入照片改为纯文字。移除动效图标，背景无需用户设置。 |
| 照片缩略图栏 | 移除独立的示例菱形图标与末尾重复加号。栏内只显示真实照片；示例从首页进入，导入从页头进入。空图库时隐藏缩略图栏。 |
| 编辑器状态栏 | 保留真实缩放复位“适应画面”，对比改成“对比原图/结束对比”。撤销、重做改为纯文字，在有对应历史时显示，没有操作历史时隐藏。 |
| 胶片页 | 保留胶片选中状态、推片 +1/+2、分类与型号选择。补齐 7 款同样式标签，不改变胶片配置或显影参数。 |
| 相纸页 | 删除纯装饰的 ▧ 占位图案。移除下拉标识，整张材料卡和“全部 8 款”均可选择真实材料；反转片继续显示直接扫描说明。 |
| 调色页 | 组别和通道选择、开关、曲线点与重置均有实际行为；移除文字旁的下拉标识。 |
| 裁切页 | “打开裁切框”去除外跳箭头；比例选择、旋转、翻转、拉直、恢复完整构图继续可用。 |
| 片边与日期页 | 选项均为实际呈现控制；保留真实样式、日期位置等文字选择按钮，去掉旁边的标识。 |
| 模拟页 | 保留真实效果滑杆、开关、画幅/测光文字选择与恢复默认，去掉选择按钮旁的下拉标识；没有增加尚未实现功能的图标。 |
| 编辑器底部 | 关于符号替换为直接可用的“诊断”文字入口；“导出照片”去掉装饰箭头。许可与关于说明可从首页进入。 |

显影引擎、材料资源、CPU 库和原始授权标签保持原字节。本次只涉及界面控件、标签绘制、映射与文案。实际设备检查结果见验证记录中 v0.2.4 小节。

所有操作按钮统一采用纯文字，去除文字旁的加号、外跳箭头、下拉符号等装饰标识。影像、胶卷插图和真实表单状态仍按各自用途显示。
