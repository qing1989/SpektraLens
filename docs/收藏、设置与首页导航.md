# 收藏、设置与首页导航

2026-11-22 接入。三个功能共用首页底部入口，数据都在本机 `darkroom` SharedPreferences，不联网、不上传。

## 首页导航

- `MainActivity.buildHomeNav()` 在 `homeStage` 底部叠加 94dp 纯黑渐隐遮罩（`0x00000000 → 0xc7000000 → 0xf5000000`）与居中悬浮胶囊（3 Tab 时最大宽 280dp、扩展至 4+ Tab 自动扩至 336dp，窄屏按屏宽减 32dp 自适应、高 58dp、底边距 14dp、四周 4dp 内边距）。
- 胶囊使用 96% `SURFACE` + 0.75dp `OUTLINE` 细描边；等分槽位高 50dp，选中块以 `SELECTED` 满槽填充，与外胶囊严格同心（29 − 4 = 25dp）。
- 每项采用 19dp 线性图标（`ic_ui_nav_home` / `ic_ui_nav_lighttable` / `ic_ui_nav_settings`，24×24、1.75px 圆头描边）+ `TYPE_MICRO (11sp)` 文字；选中态图标与文字均为 `GOLD`（Semibold），未选为 `MUTED`（Regular）。
- **2026-11-23 方案 B 真平级直接切换**：`homeStage` 作为一级 Tab 容器，通过 `HomeTab` 枚举（`HOME / LIGHT_TABLE / SETTINGS`，便于后续新增「照片边框」等独立工作台 Tab）在「首页 / 观片台 / 设置」三页间直接平级切换、底栏保持不动且高亮原地切换；三页均去掉顶栏返回箭头，系统返回键在非首页 Tab 回到首页 Tab。仅进入编辑页、关于页/赞助页等真正二级页时隐藏底栏。
- 照片多选/批量粘贴时，以及观片台处于「选中照片」或「3× 放大镜」态时（观片台在底部原位切换为上下文操作条），统一经 `syncHomeNavVisibility()` 隐藏底栏，杜绝双层底栏；退出上下文态后自动恢复。首页内容底部保留 96dp，设置页底部保留 104dp，观片台底部预留 84dp 避让底栏。
- 切离「观片台」Tab 时立即释放其位图与预烘焙底板（不占用编辑页 50MP 导出内存），切回时按最新图库即时重建并保留 `prefs.lighttable_state` 排版；再次点击已选中的「首页」Tab 平滑滚回顶部。
- 「设置」图标右上角 6dp 金色圆点（`home.nav.dot`）表示有可用更新；角标由 `refreshUpdateNotice()` 统一刷新，安装到目标版本或清单失效后消失。

## 胶片收藏

- 数据：`prefs.favorite_films`，JSON 数组，保存胶片 `Stock.id`；`loadFavoriteFilms()` / `saveFavoriteFilms()` / `toggleFavoriteFilm()`。
- 分类顺序固定为「全部 / 收藏 / 彩色负片 / 电影胶片 / 反转片 / 黑白」，整行 `HorizontalScrollView`，各分类分别记忆横向位置。
- 普通分类长按任意胶片：缩略图上覆盖半透明黑遮罩，中央显示星形按钮并触发长按触感。点击收藏/取消收藏，当前分类、滚动位置和当前胶片不变。
- 已收藏胶片在普通分类右上角显示 16dp 金色实心星，无底板背景。
- 「收藏」tab 按彩色负片 → 电影胶片 → 反转片 → 黑白分组，组内按目录顺序；不显示右上角星标。长按后中央显示实心星，再点一次取消收藏。空状态只显示「长按胶片可收藏」。
- 图标：`ic_ui_film_favorite_add.xml`（1.75 空心星）、`ic_ui_film_favorite_remove.xml`（纯填充实心星）。

## 设置页

- `SettingsPage.java`，平级一级 Tab 形态（去掉顶栏返回箭头，改为左对齐 22sp Bold 标题「设置」），底部留白 104dp 避让共享悬浮 3-Tab 导航；按系统返回键切回「首页」Tab，切入时自动刷新缓存大小与更新圆点。
- 编辑：`show_editor_strip`（显示照片缩略图条，默认关闭，保留用户已保存的选择）、`haptics_enabled`（操作震动反馈，默认开，同时控制 `Haptics.enabled`）。
- 更新：`auto_check_updates`（启动时检查，默认开）、`wifi_only_updates`（仅非计费网络下载，默认开）。检查更新仍可手动从「关于」进入。
- 存储：显示 `cacheDir` 占用，清理只删除缓存目录，不影响原照片、编辑参数和已导出相册文件。
- 关于：显示版本号与更新圆点，进入现有 `AboutPage`（项目地址、内核、作者小红书、免责声明）。首页不再有独立「关于」入口。
