# SpektraLens 配色与字体

更新日期：2026-11-18。

本次调整改变界面铬层、文字、控件状态与轮廓，不改变功能结构、字号阶梯、触控尺寸或照片处理参数。布局仍沿用[C 方案：轻盈浮层](C方案界面.md)。2026-11-16 用户补充要求按效果图校正形状：普通圆角矩形仍用三档半径，胶囊控件则按实际短边的一半绘制，不再用固定 10dp / 16dp 半径近似。

## 2026-11-18 · 短暂提示统一

所有应用自身短暂反馈复用 `AppNotice`，只含 `TYPE_BODY` 正文和现有 `CONTROL / OUTLINE / INK` 胶囊样式，不含 App 图标。Activity 和 Dialog 分别使用自己的窗口，图库提示浮在弹窗内容上方；连续反馈互相替换，关闭窗口清理。使用原有 140ms 淡入淡出，长错误消息保留较长时长，并遵守系统无障碍推荐时长。既有页面 Logo、导入进度 Logo 和系统权限/安装流程不属于此类文字提示。

## 2026-11-18 · 导入按钮的进度状态

导入进度直接作为原首页按钮的背景绘制，胶囊半径按实际短边的一半计算，位置与 54dp 高度保持一致。文字使用 TYPE_BODY 白色粗体、按整个按钮中线居中，右侧取消通过左右对称留白避让；无独立矩形和 Logo。完成、失败或取消恢复普通按钮样式，保留整体进度和光谱配色；暂停或系统关闭动画时停止流动。

此项替代历史的 10dp 矩形进度槽与 Logo 方案。

## 2026-11-18 · 大字体与窄窗口补齐

关于页和批量底栏共用 `AdaptiveActionRow`，根据实际字体测量和容器可用宽度横排或竖排，取消固定字号/屏宽阈值。字号不降低；操作触控至少 48dp，必要时按完整文字高度增高，关于页两颗按钮保持等宽等高、横排底边对齐，更新角标仍预留空间。

导入按钮由 `ImportButtonLayout` 保持居中，依据取消按钮实际宽度对称留白。完整进度放不下时显示完整张数，读屏保留完整文案；普通字号仍保持 54dp，大字体按文字增高。相册两处授权入口的 44dp 均转换为实际像素。批量浮层增高后同步调整列表留白和提示浮层位置，避免遮住内容。

## 字体

- Inter 4.1 可变字体负责西文、数字和 `SpektraLens` 字标。
- Noto Sans SC 可变字体负责中文。
- Android 29+ 的 `Typeface.CustomFallbackBuilder` 以 Inter 为主字体、Noto Sans SC 为首选回退、`sans-serif` 为系统回退，中文和西文可在同一行内自动切换。
- Regular、Medium、Semibold、Bold 分别写入两份可变字体的 `wght` 轴，并把相同字重交给 `FontStyle` 参与回退选择，避免只切换字体文件却由系统合成字重。
- 数字在 Inter 上启用 `tnum`；字标使用 Semibold 与约 `-0.035em` 字距。
- 字体来自官方发行文件，随 APK 本地提供，不使用 Downloadable Fonts、运行时网络请求或第三方抽取子集。
- 原始 SIL OFL 1.1 文本随 APK 的 `licenses/` 提供，可从“关于 → 许可全文”查看。

## 实现与约束

共享 token、字体缓存和控件状态集中在 `AppStyle`。主按钮使用象牙色填充和深色粗体文字；次级按钮保持灰色胶囊或纯文字；选中态使用金色文字、描边或状态，不使用金色大块按钮。

导出面板打开时，编辑页顶栏的“导出照片”降为深灰胶囊；面板关闭后恢复象牙色主按钮。参数滑条、胶片配方、导出编码、更新协议和签名流程均未因本次视觉调整改变。

## 2026-11-17 · 弹窗字号

系统弹窗默认用 22sp 标题与 16sp 列表项，黑白滤镜这类较长的说明会被挤成两行。共享弹窗样式改为直接套页面字号阶梯：

- 标题用 `TYPE_HEADING`（18sp）+ `FONT_SEMIBOLD`。
- 单选、多选和普通列表项用 `TYPE_BODY`（13sp）+ `FONT_REGULAR`，折行时补 2dp 行距。
- 正文消息保持 15sp 与 4dp 行距，操作按钮保持 14sp，不改胶囊形状与排版规则。
- 列表新增或复用的行由 `OnHierarchyChangeListener` 再次套用同一字号，不回到系统默认值；不使用会在字号修改后反复触发布局的全局布局监听。

设计依据是本轮黑白原型里的弹窗标题 17px / 选项 13px；按项目“只从六档里选”的规则分别落到 18 与 13。该项只影响文字，不改变弹窗宽度、按钮和触控高度。

- 最近照片标题、格式与大小、状态行继续使用 `TYPE_BODY`、`TYPE_MICRO`、`TYPE_MICRO`；“暂未编辑”改用 `MUTED`，只有已保存调整的胶片名使用 `GOLD`。

- 2026-11-21 RAW 空状态文案从 TYPE_HEADING（18sp）降为 TYPE_TITLE（15sp）；图标下说明按空状态标题处理，TYPE_BODY（13sp）更接近辅助说明，未采用。
- 相册部分授权入口由 30dp 提高到 `TOUCH_MIN`（44dp），步骤把手仍为纯视觉装饰，不冒充按钮。

- 批量模式为所有卡片显示 22dp 选择控件：未选中为深色半透明圆加 1dp 白边，选中为金色圆加 Material `check`；勾选只动画更新目标卡片的遮罩与控件，22dp 金色收藏心形同步在 8dp / 38dp 两个右边距间让位并保持可见，不重建整列缩略图。
- 当前相册在相册列表中用 `GOLD` 文字、等宽数字计数和 Material `check` 同时标识；无参数快照时“粘贴编辑参数”和“批量粘贴编辑参数”使用 `DISABLED` 且不响应点击。
- 最近照片长按面板固定使用 `TYPE_HEADING + FONT_SEMIBOLD` 的「更多操作」标题，取消按 2026-11-18 确认稿使用 `TYPE_BODY + FONT_MEDIUM`；不再显示照片信息眉题或照片名。正文左右 18dp，按「编辑 / 编辑参数 / 照片管理」三组组织，标题下不放横线，组内分隔线内缩 16dp。操作正文使用 `TYPE_BODY + FONT_MEDIUM`，编辑项为 `GOLD + FONT_SEMIBOLD`，删除项使用 `DANGER`，普通项使用 `INK`。分组标签与右侧状态使用 `TYPE_MICRO + FONT_MEDIUM`，说明为 `TYPE_MICRO + FONT_REGULAR`；禁用时三类行内文字统一 `DISABLED`，不再对整行额外降低透明度。面板四角 `R_LARGE`、三张 `CONTROL` 卡片 `R_MEDIUM`；通过透明窗口保留左右与底部各 10dp 空间。
