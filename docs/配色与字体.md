# SpektraLens 配色与字体

更新日期：2026-11-16。

本次调整改变界面铬层、文字、控件状态与轮廓，不改变功能结构、字号阶梯、触控尺寸或照片处理参数。布局仍沿用[C 方案：轻盈浮层](C方案界面.md)。2026-11-16 用户补充要求按效果图校正形状：普通圆角矩形仍用三档半径，胶囊控件则按实际短边的一半绘制，不再用固定 10dp / 16dp 半径近似。

## 字体

- Inter 4.1 可变字体负责西文、数字和 `SpektraLens` 字标。
- Noto Sans SC 可变字体负责中文。
- Android 29+ 的 `Typeface.CustomFallbackBuilder` 以 Inter 为主字体、Noto Sans SC 为首选回退、`sans-serif` 为系统回退，中文和西文可在同一行内自动切换。
- Regular、Medium、Semibold、Bold 分别写入两份可变字体的 `wght` 轴，并把相同字重交给 `FontStyle` 参与回退选择，避免只切换字体文件却由系统合成字重。
- 数字在 Inter 上启用 `tnum`；字标使用 Semibold 与约 `-0.035em` 字距。
- 字体来自官方发行文件，随 APK 本地提供，不使用 Downloadable Fonts、运行时网络请求或第三方抽取子集。
- 原始 SIL OFL 1.1 文本随 APK 的 `licenses/` 提供，可从“关于 → 许可全文”查看。

## 实现与约束

共享 token、字体缓存和控件状态集中在 `AppStyle`。主按钮使用象牙色填充和深色粗体文字；次级按钮保持灰色胶囊或纯文字；选中态使用金色文字、描边或状态，不使用金色大块按钮。

导出面板打开时，编辑页顶栏的“导出照片”降为深灰胶囊；面板关闭后恢复象牙色主按钮。参数滑条、胶片配方、导出编码、更新协议和签名流程均未因本次视觉调整改变。

## 2026-11-16 · 控件形状逐项校正

依据为交接目录 `mocks/after/` 全部主页面、赞助三页，以及用户补充的导出按钮、开关、基础页签、数值框四张局部参考。下面记录的是源码核对和修正；设备截图验收尚未执行。

| 页面 / 控件 | 校正 |
|---|---|
| 首页导入、编辑顶栏导出 | 使用 `pillAction()`，端部随最终高度形成半圆；正常、禁用、按下遮罩共用轮廓。 |
| 胶片型号 / 相纸与印相、胶片分类 | 选中背景改为胶囊；胶片分类按实际文字宽度加左右各 9dp，最小 40dp、最大 70dp，使「全部」不虚宽，同时「彩色负片 / 电影胶片 / 反转片」完整可读；胶片缩略图与相纸材质卡仍保留普通圆角矩形。 |
| 调整二级页签 | 基础、曲线、色彩平衡、HSL、暗角共用胶囊选中背景。 |
| 全部参数数值框 | `0.00`、EV、倍率和其他单位的外框改为胶囊；保留宽高、字号适配与 Inter 等宽数字。 |
| 全部开关 | 原生 `Switch` 配自定义轨道和旋钮：标称 44×26dp 轨道、22dp 圆形旋钮、2dp 边距；明确开、关、禁用颜色，保留原生状态和事件。 |
| 底部四工具导航 | 外框与内部选中块都用实际尺寸胶囊；去掉选中块重复的纵向内缩，总留白约 5dp。 |
| 编辑参数面板 | 保留 26dp 圆角矩形，移除设计图没有的外描边与阴影。高度、开合动画和预览空间预算不变。 |
| 编辑面板说明 | “质感从胶片计算而来”“反转片直接扫描”“裁切与几何”“印相材料”等说明标题使用 `TYPE_BODY` + `FONT_BOLD`；紧随其后的说明正文继续使用 `TYPE_MICRO` + `MUTED` + `FONT_REGULAR`，标题与正文共用 `panelNote()` 或同一字重规则。 |
| 边框 / 日期选项、质感及未出图调整子页 | 通过公共按钮入口统一胶囊，不再出现小圆角的长条按钮。 |
| 导出面板 | 保存按钮为胶囊；格式 / 画质保留嵌套圆角矩形，选中底改用 `SURFACE` 与 `CONTROL` 轨道形成区分，未选文字用 `MUTED`。 |
| 关于 / 更新 / 图库权限 / 系统弹窗 | 主次操作按钮统一胶囊；版本、许可与更新角标也按内容高度形成胶囊。关于页“检查更新”和“赞助开发”按两组文字中较大者生成同一宽高并底边对齐，更新角标的预留空间不再使主按钮偏宽或下移。 |
| 赞助说明 / 赞赏码 | 主次按钮统一胶囊；说明面板改为四角圆润、左右与底部留白的浮层，信息卡使用 `CONTROL` 与外层区分。 |

`R_SMALL / R_MEDIUM / R_LARGE` 仍为 10 / 16 / 26dp，分别用于输入框与状态条、卡片与嵌套分段、面板与弹层。胶囊属于独立形状规则，不是第四档固定半径。导出分段选项、图片卡片和多行文本输入框不应改成胶囊。

本轮未修改 `AdjustmentSeekBar`，`sliderColors()` 与修正前逐字一致；参数轨道、白色滑块、过零触感及双击复位沿用原实现。
