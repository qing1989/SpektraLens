# 最近照片、复制参数与批量导入

## 首页导入

- 首页按钮为「开始导入照片」，导入完成后停留在首页，不自动进入编辑页。
- 图库为空（首次安装或全部删除）时，导入区下方不再显示「导入后停留在此页，点击照片即可立即编辑」；该行只用于导入进度和失败提示。标题固定为「最近照片 · x 张」，数量使用 11sp 次要色并与标题基线对齐；右侧只保留「照片管理」入口，无照片时隐藏。
- 手机相册图库默认展示“最近照片”，按拍摄时间从新到旧排列。标题下方不再显示“图库”眉题；标题与右侧“已选 x 张”处在同一水平中心线，白色 Material 下箭头紧贴标题。
- 选择器允许一次选择 1～20 张静态照片；达到 20 张后继续点击只提示“最多选择 20 张照片”，既不清空此前选择，也不加入第 21 张。单选模式只用于导出成功后的「再编辑一张」。
- 点击相册标题后，相册列表直接在标题下方展开并接管照片网格区域，不再叠加第二个对话框或浮动卡片；关闭后恢复网格。行高 54dp，文字补 2dp 行距；选择相册后收起列表并刷新网格。
- 相册列表显示“最近照片”和各个相册，并用金色文字、数量与 Material `check` 标出当前相册。底部固定为等高等宽的两个 48dp 胶囊：深灰「取消」和橙色「确认导入」；没有选中照片时确认按钮禁用。
- 仅查询和导入 `JPG`、`PNG`、`HEIC`、`HEIF` 与 `DNG`。视频、动图不进入应用图库；Live / Motion Photo 导入其静态帧，motion 视频数据丢弃。
- 网格只读照片元数据，不读 MediaStore 的 XMP 大字段，也不在点选或导入时做 Motion 拦截；动态照片按普通静态照片显示、选择和导入。
- 批量导入逐张处理，单张失败不会阻断后续照片。取消或 Activity 销毁时，本次尚未提交的文件和缩略图会清理。
- 导入过程中直接复用首页原「开始导入照片」按钮：背景变为胶囊形光谱进度，位置、宽度和 54dp 高度不变，文字在整个按钮中线居中，不再额外覆盖矩形进度区域或显示 Logo。右侧取消和返回取消保留；完成或取消后恢复原按钮。全部成功时停留首页并更新提示，只有全部失败或部分失败才显示结果弹窗。
- 每次导入提交后，“最近照片”按最近导入时间重新排序，再次导入的旧照片也会回到第一张；同一批导入内按拍摄时间新到旧排列。首页顶部横幅始终显示排序后的第一张，并可从横幅直接进入该照片的编辑页。

## 2026-11-18 · UI 走查后的适配补齐

- 「允许访问相册」「可见部分照片 · 管理」均按 44dp 设置高度，修正裸像素遗漏。
- 导入按钮依据实际可用宽度显示完整进度；放不下时精简为完整的「当前 / 总数」，字号保持原样，读屏说明保留完整文案。文字始终居中，取消入口可用；普通字号保持 54dp，大字号按文字高度增长。
- 批量底栏的按钮按实际文字宽度自动横排或竖排，高度随字体增长，照片列表和反馈浮层按实际底栏高度避让；常规字号继续使用原有横排布局。
- 首页横幅、照片缩略图、长按菜单编辑操作统一进入展开的「胶片型号」页，保留照片保存的胶片、参数和撤销记录。

## 照片管理（2026-11-18）

- 首页标题右侧的「照片管理」为 13sp、金色、左侧 14dp 留白、44dp 触控高度；没有照片时隐藏。
- 点击后进入多选：右上原位替换为「全选 / 取消选择」，其余首页入口锁定，导入按钮、关于与首页大图均不响应；滚动与照片勾选保留。
- 「全选」无视当前勾选，一次性选择全部照片；「取消选择」清空全部勾选，没有勾选时置灰不可点。
- 点缩略图切换勾选，长按不再打开「更多操作」，标题与参数区不响应。勾选沿用 22dp 金色圆 + Material check、未选中深色半透明圆加白描边、40% 黑色遮罩与收藏心形左移 38dp 的既有视觉。
- 底部操作栏与导入相册一致：左右 14dp、底部 14dp 内边距，两个等宽胶囊，均 48dp 高、间距 12dp。取消为深色胶囊，删除为象牙白底深色「删除 · x 张」；未选择时删除置灰不可点。
- 取消、返回手势都先退出多选并清空勾选，恢复常态。该模式与批量粘贴互斥；开始导入等入口在多选期间被阻止。
- 点删除弹出与单张删除相同的确认框，仅标题为「删除所选照片？」，正文与按钮不变。确认后一次性写入新的图库记录，失败整体回滚；成功后逐张清理照片文件、缩略图、显影效果与画廊缓存。
- 全部照片删除后自动载入内置示例、清除遗留 source.img，首页横幅绑定打包的示例图；只删除部分照片时横幅继续跟随剩余最近一张，当前编辑照片被删则回到示例。

## 超大相册加载（2026-11-18）

- 小米 15 等机型系统相册近万张照片时，导入弹窗曾长时间停在「正在读取相册…」。原因是列表查询把 XMP 列一起取回，厂商 Provider 为每张照片保留多 KB 的 XMP，逐行读取会让 CursorWindow 反复重填，查询被拖到分钟级。
- 列表改为分页读取，每页 400 行（Android 11 及以上使用 `QUERY_ARG_LIMIT` / `QUERY_ARG_OFFSET`），首页到达就立刻显示，余下页面在后台继续追加；读取期间不影响勾选、切换相册或确认导入。
- 分页状态由 `GalleryPaging` 维护：短页、空页、厂商无视 limit（一次返回全部）都判定为结束；某页全是已出现过的照片说明厂商无视 offset，回退为一次性全量查询，避免只显示前 400 张或无限循环。整页都是不支持的格式时继续读取下一页，不会提前结束。
- 部分页面读取失败时保留已经显示的缩略图；只有一张都没拿到时才显示「相册暂时无法读取」。
- Android 10 不支持分页参数，仍走一次性全量查询，但同样不再读取 XMP 列。

## 持久化与失败恢复

- 批量导入先把每张照片复制到临时文件并完成解码、缩略图生成；全部处理结束后再提交 `library.json`。提交失败时移除本批内存记录并删除已复制照片与缩略图。
- 删除照片时先成功写入新的 `library.json`，再删除应用内副本、缩略图与显影缓存；写盘失败时照片和编辑记录保持可恢复。
- 收藏和单张／批量粘贴写盘失败时都会回滚内存状态，不把未持久化的结果留在界面上。
- 收藏角标默认位于右上角；进入批量选择后收藏角标先左移，Material 选择控件显示在最右侧，两者在选中与未选中状态下都必须可见。

## 图标与许可

- 相册箭头、收藏、批量勾选和关于页导航箭头使用 Google Material Icons 本地 VectorDrawable，许可为 Apache-2.0。
- 应用不引入 Google Font、运行时图标 SDK 或网络加载。来源和许可见 `Material-Icons-NOTICE.txt`、`Apache-2.0.txt`、`NOTICE` 与 `UPSTREAMS.md`。
