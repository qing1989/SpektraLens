# 画廊与首页缩略图性能优化

2026-11-18，用户批准同时优化胶片画廊和首页粘贴参数后的效果图。正式版本仍为 0.4.6 / 25，并存版本仍为 0.4.6-uitest3 / 2502；本轮未打包或发布。

## 胶片画廊

- 首先读取 16 MiB 内存缓存；没有时异步读取应用私有 `cache/film-thumbs-v1`，使用 64 MiB LRU 和无损 PNG。更换照片后返回、重新启动进程或同一后端重新启动引擎，都可以复用有效文件；系统清除缓存后按原流程重建。
- 磁盘键包含原片私有路径、大小、修改时间、安装更新时间、引擎资源 `.ready` 指纹、实际后端及 capabilities、独立中性胶片配方和输出长边。用户曝光、曲线、HSL、相纸、颗粒、边框、日期等二次编辑不参与。内存指纹另保留载入代次与 bitmap 身份；后端发生回退时也失效。
- 选中的可见卡片最先处理，再处理其他实际可见项，最后补 60dp 缓冲。命中磁盘时不占显影队列；未命中仍逐卷重新 open，并经 FilmStockPolicy 生成参数。普通源图 openFile 1024px、显影参数 800px、返回长边 256～512px、空二次编辑参数以及 product_defaults 仅用于 open 的约束不变。
- 单个显影 worker 继续串行服务主预览、画廊和首页效果图。主预览在途时不启动新的缩略图显影；已运行的一张完成后让出队列。打开缩略图前与 finally 中清空 openedSource。
- PNG 编码在独立 I/O 线程完成，最多两份缓存写入副本在途，达到限制时暂停新的画廊显影，写完再补。临时文件原子改名，读取损坏文件时回落重算；删除照片后清理对应前缀，缓存淘汰不触碰原片。

## 首页粘贴后的效果图

- 原先整批 for 循环改为 ThumbnailWorkQueue：每次只取一张，首页横幅、可见卡片优先，其余按入队顺序；每张完成后回到 UI 再调度下一张。进入编辑页、主预览在途、导入或导出期间暂停后续首页显影，返回首页及操作结束后恢复。
- 同一照片只保留最新参数。相同参数已入队、正在显影、正在保存或已有有效效果图时复用结果；新参数、编辑或删除立即撤销旧任务令牌。参数与收藏等原有业务持久化流程继续保留。
- 批量路径只读取 EXIF / RAW 元数据，源图由 openFile / openRaw 解码；删除原先在主进程先 readPhoto 一次却不使用其 bitmap 的重复解码。首页效果图继续使用 1024px 长边和该照片全部编辑参数。
- 新生成的 bitmap 直接转交 HomePhotoImages；可见卡片按既有面积平均算法裁切后先显示，再保存原有 JPEG 效果图。首轮显示不经过 JPEG 写入、JPEG 解码和 PNG 再编码。离屏后仍可沿用原有首页磁盘加载路径。
- 保存使用 ThumbnailWriteGate：参数变化、删除、较新的保存请求和关闭页面都会阻止旧文件发布；原子改名与令牌失效互斥。View 另有图片代次，防止被取消的旧加载回调清空新结果的尺寸。最多两张后台效果图等待保存，避免整批 bitmap 堆积。
- PendingBitmaps 在页面关闭时回收尚未接收的 Handler 结果；已转交 I/O 的 bitmap 通过 finally 释放。进程中断后，回到首页会为已编辑而缺少效果文件的照片补图。当前主预览只有在照片 ID、配方与完成状态均匹配时才能落盘，不能把旧预览保存为新配方。

## 本轮验证

- `/usr/bin/python3 scripts/test_thumbnails.py` 实际运行生产队列、写入门和磁盘缓存，共 48 项检查。20 张任务的确定性执行模拟得到 `photo0 → main-preview → photo19`，剩余 18 张仍在队列；验证主预览可以插入、可见项提升、重复合并、最新参数胜出、暂停重试、删除失效、写入与失效竞争、原子失败保留旧文件、LRU 上限、跨实例复用和原片保留。
- Android 主代码与 instrumentation 源码编译、testThumbnailPolicy、testLibraryPolicy、testFilmStockPolicy、testUpdatePolicy 和 lintDebug 通过，共 711 项 JVM 策略检查；Lint 0 错误、6 项既有警告。
- 补充设备用例：清空内存后从 PNG 恢复画廊，像素逐字节一致且不增加显影次数；损坏一份缓存只重算该项；首页显示发生在 JPEG 保存前；保存暂停期间失效不会复活旧文件；关闭后回收未接收位图。这些设备用例仅编译，未执行。
- 本机 Apple M4 / Metal safe-math 原生回归通过：四款黑白中性灰、灰阶、颗粒与实拍参考检查通过，live/full 最大 16 位通道差为 0，切回彩色逐字节恢复。
- 本机 Android SDK 缺少 emulator、系统镜像与 sdkmanager；旧 BookVoice AVD 指向的目录已不存在，adb 无连接设备。本轮没有运行 Android 模拟器或真机，没有测得 Android 冷/热缓存耗时或帧率；JVM 队列模拟与 Metal 回归不能替代这些结果。

日志、修改前快照和 Metal 结果保存在 `.local/thumbnail-performance-2026-11-18/`。本轮没有改版本号、签名密钥、latest.json、提交、推送或 Release；已有交付 APK 不包含这些优化。
