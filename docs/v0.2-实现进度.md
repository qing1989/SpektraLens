# v0.2 实现进度

用户本轮要求：RAW 解码、原尺寸导出、完整调色能力、裁切/几何调整、片边/日期、更细的模拟控制。保留现有黑色流动背景、授权 GRLife 图标和大图在上/缩略图在下的布局。

实现目标与验收：

- [x] 固定 LibRaw 0.22.2，Android NDK 本地解码；真实相机样片与无内嵌预览的合成 DNG 验证。
- [x] 单独读取原文件重新显影导出，移除 2560 上限；显示真实输出尺寸，内存失败保留照片与设置。
- [x] 共用预览/导出的调色处理：白平衡、曝光/对比/亮度、阴影/高光、黑白场、饱和、分区色彩平衡、RGB/Luma/单通道曲线、暗角。
- [x] 非破坏裁剪、比例、旋转、翻转、拉直；预览与输出同一几何。
- [x] 可导出的片边与日期呈现层，明确与 SpektraLab 负片曝光级物理片边模型的差异。
- [x] 接入模拟细项，并修正反转片直接扫描/相纸联动及产品曝光默认值。
- [x] 编辑参数逐照片保存/撤销，JPEG/PNG/TIFF 导出与变更来源记录。
- [x] 构建/Lint、Android 真正解码/渲染/输出测试、UI 操作与打包校验。

实现约束：不修改胶片测量数据；保留上游源码；在 Android 新增适配层与处理链。尚未验证的机型、物理模型一致性和极大图内存边界如实记录。

已研究：LibRaw/LibRaw，Yalantis/uCrop，SpektraLab 的 Layer 2 / Windows RAW 路径。LibRaw 固定源 commit `b93f6e45c194f5df9b02a43b1af9a54b4f41f33f`，tree `0fd7d10c62714db90d9fa922230916a030c2d6d3`。真实样片从 rawpy 官方测试仓库下载，仅作本地验证，不打包相机样片。


完成版本：v0.2.0（2026-11-01）。17 项真实设备测试通过，RAW 原尺寸、16 位编码与预览编辑链均有独立文件证据。裁切/曲线 UI 与扫描后的片边日期已操作并导出。详细证据及未覆盖范围见 [验证记录](验证记录.md)。

实现边界：扫描调色在 sRGB 进行；RAW 白平衡为拍摄白平衡，冷暖/色调控制是扫描后偏移；片边和日期是呈现层而非桌面物理曝光模型。原尺寸移除软件 2560 上限，仍受设备可用内存与 Vulkan 限制。
