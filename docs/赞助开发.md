# 赞助开发

2026-11-16 接入。该功能只提供自愿支持开发的入口，不构成购买、订阅、会员或任何功能解锁。

## 产品边界

- 仅使用微信赞赏码；当前不提供支付宝个人收款码入口。
- 赞赏码单笔上限按用户的微信设置显示为 ¥50。
- App 不接入微信支付或支付宝 SDK，不创建订单，不校验或记录付款结果。
- App 不读取、保存或上传付款者信息，不增加支付埋点、设备标识或遥测。
- 赞赏码图片随 APK 本地展示并保存到 `Pictures/SpektraLens`；显示不依赖网络。
- 实际付款由微信处理，可能使用网络并按微信的账户风控核验收款人姓氏。
- 关于页写明“请仅从 SpektraLens 官方签名的 Release 获取本应用”。

## 界面与交互

1. 关于页在“检查更新”旁显示次级纯文字按钮“赞助开发者”。
2. 点击后打开底部说明面板，明确完全自愿、隐私边界和单笔上限；点击“以后再说”或面板外的遮罩区域都可关闭。
3. 点击“查看微信赞赏码”进入全屏页；该页顶部仅保留返回按钮，系统返回先回说明面板，再回关于页。
4. “保存赞赏码”通过 MediaStore 写入 `Pictures/SpektraLens`，保存的是 APK 内原始 JPEG 字节，不重新编码二维码。
5. 所有可点击控件继续使用系统触感反馈。

## 私有素材注入

公开仓库不提交二维码原图。默认私有路径：

```text
.local/sponsor/wechat-appreciation.jpg
```

`.local/` 已被 Git 忽略。构建时也可以指定其他 JPEG：

```sh
python3 scripts/build.py -PsponsorQr=/absolute/path/to/wechat-appreciation.jpg :app:assembleRelease
```

或：

```sh
SPEKTRA_SPONSOR_WECHAT_QR=/absolute/path/to/wechat-appreciation.jpg \
  python3 scripts/build.py :app:assembleRelease
```

`prepareSponsorAsset` 会验证 JPEG 文件头，再以 `res/raw/sponsor_wechat_qr.jpg` 注入构建目录。App 通过资源名动态检测素材：

- 找到素材：显示赞助入口和完整页面。
- 没有素材：完全隐藏赞助入口，应用其余功能不受影响。

公开源码构建必须使用：

```sh
python3 scripts/build.py -PpublicBuild=true :app:assembleDebug
```

该参数会删除先前生成目录中的赞助码资源，并保证公开构建不显示入口。

## 验证

```sh
python3 scripts/build.py \
  :app:compileDebugJavaWithJavac \
  :app:compileDebugAndroidTestJavaWithJavac \
  :app:lintDebug \
  --offline
python3 scripts/test_sponsor_assets.py
```

`test_sponsor_assets.py` 会分别处理公开构建和私有构建，并检查：

- `-PpublicBuild=true` 后，`sponsor-res/raw/sponsor_wechat_qr.jpg` 与合并资源符号均不存在。
- 使用默认私有素材后，生成文件与源 JPEG 字节一致。
- 真机检查关于页入口、返回层级、二维码保存路径和大字号滚动。
