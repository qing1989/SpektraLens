# 编辑滑杆样式 · 2026-11-04

按用户参考图调整所有编辑参数滑杆，使用项目自己的 Android 控件绘制，没有复制参考应用的图标或图片素材。

每项在同一行展示：参数名称、渐变细轨道与白色胶囊滑块、右侧等宽数字框。整行高度 56dp，滑杆触摸区域高 48dp；数值框保留原参数的小数精度、正负号和单位。轨道粗 3dp，白色滑块 30×20dp，并为端点完整轮廓预留内边距。

| 参数语义 | 配色 |
|---|---|
| 冷暖 | 蓝 → 中性灰 → 橙 |
| 绿/洋红、洋红滤色 | 绿 → 中性灰 → 洋红 |
| 黄色滤色 | 蓝 → 中性灰 → 黄 |
| HSL | 对应所选的红、橙、黄、绿、青、蓝、紫、洋红；色相显示相邻色，饱和度由灰过渡到选中色，明度由暗到亮 |
| 色彩平衡 | 色相使用色谱；着色强度的终点随当前区域色相同步变化 |
| 曝光、亮度、明暗、黑白场、暗角 | 暗灰 → 亮灰 |
| 其他模拟强度、边框与日期参数 | 灰 → 琥珀 → 应用橙色 |

原生 SeekBar 继续负责触摸、范围、步进、键盘及无障碍交互；仅替换轨道和滑块外观。Android 11+ 的无障碍状态描述显示实际参数值。光谱引擎、调色计算、导出处理未修改。

构建与 Lint 通过：0 Error/Fatal，7 条既有提示。编辑布局、工作流和系统触感 8 项设备测试通过（17.802 秒）；现有滑块端点测试覆盖当前工具与真实 HSL 分组。通过实际触摸验证冷暖 −100 / +100、数值同步、HSL 颜色切换、色彩平衡轨道联动；着色强度右端由 RGB(238,87,87) 随色相改变为 RGB(87,87,238)。320dp 窄屏实测名称、轨道、数值框无重叠；检查结束后恢复原模拟器尺寸。

本地开发预览沿用原授权胶片图标，裁切工具保持暂时下线，自动测光默认关闭。手动检查的临时参数已通过正常新导入清理，预览停在“调整 → 基础”。没有重生成或覆盖已有交付包。截图和原始验证日志位于忽略的本地 `.tooling/effect-audit/slider-review/`，不进入公开仓库。
