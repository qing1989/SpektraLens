# 黑白胶片接入

本轮是 0.4.6 之后的源码开发，尚未发布。版本号保持 `0.4.6 / 25`，没有修改签名、联网范围或更新清单。

## 范围与来源

从当前固定的 SpektraLab `267ee24380091e5bee87658d00f6c33d77321194` 接入四款黑白胶片和一款银盐相纸：

| 胶片 | 配置 ID | 默认颗粒系数 |
|---|---|---|
| Kodak Tri-X 400 | `kodak_tri_x_400` | 1.70 |
| Kodak T-Max 100 | `kodak_tmax_100` | 0.74 |
| Fujifilm Neopan 100 Acros II | `fujifilm_neopan_acros_100_ii` | 0.64 |
| Ilford HP5 Plus 400 | `ilford_hp5_plus_400` | 1.49 |

配套相纸为 Ilford Multigrade IV RC（`ilford_multigrade_iv_rc`）。

五份 JSON 来自 `SpektraLab/engine/resources_product/profiles/`，保持原始字节、metadata、厂家资料来源和假设标注。颗粒系数来自同一提交的 `modern_UI/Spektrafilm/Spektrafilm/Model/Params.swift`，无需更新整个上游或修改数值内核。

`scripts/prepare_resources.py` 明确追加上述五份配置和 CineStill 800T 的 alias 配置，不顺带加入同目录的其他产品；原有 28 份彩色配置和 `neutral_print_filters.json` 保持不变。目录合计为 25 款胶片、9 款相纸 / 拷贝片。原始产品数据 NOTICE 以 `licenses/SpektraLab-Product-Data-NOTICE.txt` 随应用提供，关于页补充作者署名。

## 界面与状态

- 胶片分类新增“黑白”，使用现有的真实照片方形缩略图和选中样式；分类胶囊恢复 0.4.5 的等宽槽位规则，五个分类等分一行、间距 3dp，不按文字宽度动态计算。
- 新增四款项目自绘标签配置，不使用第三方图标位图；Ilford 品牌和名称正常显示。
- 选择黑白胶片时自动配对 Multigrade IV RC；黑白与彩色相纸不能混选。黑白只有一款相纸，因此材料卡展示当前相纸，省去只有一个选项的选择按钮。
- 黑白胶片页新增“黑白滤镜”整行选择器，右侧窄胶囊只显示当前颜色；六项保留“无”、黄、橙、红、绿、蓝，选择说明在弹窗中完整显示。
- “相纸与印相”新增五档“相纸反差”胶囊，默认标准（上游 2 号）；右侧只显示当前档位的效果说明，不再重复档位名。横向档位条与胶片画廊一致：点中间项不位移，只有点当前视口最左/最右且外侧还有选项时滑一格；面板重建后选中项保持可见。五档不增加额外的说明行。
- 黑白相纸保留印相亮度；黑白模式不显示彩色印相的洋红 / 黄色滤色滑块。原有彩色滤色设置仍保存在照片参数里，返回彩色时继续参与显影。
- 选片与配对作为同一次编辑参与撤销 / 重做；恢复照片、导出后“再编辑一张”及会话恢复都沿用现有参数保存方式，并校正不兼容的相纸。
- 二次扫描调色、曲线、边框和日期等现有功能继续作用于主预览和导出。用户主动设置色温、颜色分级或单通道曲线后可以给黑白照片着色，不能把这种主动调色误判为胶片底色偏色。

## 显影参数

`FilmStockPolicy` 统一生成主预览、画廊及导出的黑白覆盖参数：

| 参数 | 黑白值 |
|---|---|
| `print_stock` | `ilford_multigrade_iv_rc` |
| `scan_film` | false（黑白负片仍经过印相） |
| `grain_sublayers_active` | false |
| `extended_dynamic_range` | false |
| `c_filter_neutral` / `m_filter_neutral` / `y_filter_neutral` | 按反差档位：低（0/0/199）、较低（0/0/99.8）、标准（0/0/68）、较高（0/39.1/0）、高（0/151.7/0） |
| `m_filter_shift` / `y_filter_shift` | 0 / 0 |
| `camera_filter` | 仅黑白发送；无 / 黄 `w8` / 橙 `w21` / 红 `w25` / 绿 `w58` / 蓝 `w47` |
| `print_exposure` | `2^(-print_brightness) × 相纸档位曝光`；标准档因数为 1 |

彩色胶片的滤色包与颗粒分层继续沿用 0.4.6 的参数，不因接入黑白逻辑而被改写。普通图片保留 sRGB 解码，RAW 保留线性 ProPhoto RGB；不更改既有测光默认策略。

颗粒滑块继续为 0～2，默认 1、双击恢复 1。默认位置对应上表校准值；Tri-X 和 HP5 的默认系数大于 1，为避免上游直接乘法在滑块高段提前撞上引擎上限：

- 0～1：`引擎颗粒 = 滑块 × 默认系数`。
- 1～2 且默认系数大于 1：`引擎颗粒 = 默认系数 + (滑块 - 1) × (2 - 默认系数)`。
- 其余胶片：维持乘法；彩色系数为 1，不改变既有强度语义。

该映射仅发生在发送引擎参数时，不改写用户保存的滑块值，因此来回切片、撤销和再次编辑不会累乘系数或裁掉原有强度。每个滑块步进均有实际参数变化。五档相纸映射直接使用上游 `paper_grades.json` 的滤色值与印相曝光因数，主预览、画廊默认配方和导出共用 `FilmStockPolicy`。

## 画廊约束

黑白缩略图与彩色缩略图一样，只按原片和胶片默认配方渲染。固定相纸、默认颗粒和中性参数在独立配方中设置，用户的曝光、印相亮度、曲线、颗粒、日期等不进入缓存键，不触发重算。逐卷重新 open、800px 参数下限、有限解码、可见优先、主预览优先和最终清理 `openedSource` 均保留。

## 验证方式

不生成 APK 的检查：

```sh
python3 scripts/build.py --offline \
  :app:compileDebugJavaWithJavac \
  :app:compileDebugAndroidTestJavaWithJavac \
  :app:testFilmStockPolicy :app:testUpdatePolicy :app:lintDebug

python3 scripts/test_black_white.py
```

第二条需要 JDK 17 的 `java` / `javac`，或设置 `JAVA_HOME`。它检查 34 份配置的原始字节、图标覆盖、产品署名、相纸规则、颗粒校准和每个滑块步进。

可选的本机上游 Metal 验证需要 NumPy、Pillow 和已构建的上游动态库：

```sh
python3 scripts/test_black_white.py \
  --library /path/to/libreference.dylib \
  --metal-resources /path/to/reference/resources \
  --output .local/black-white-checks \
  --photo android/app/src/main/assets/demo.jpg
```

该检查读取 Java 实际生成的覆盖参数，验证四款胶片的中性灰、18% 中灰、灰阶顺序、默认效果、真实颗粒变化、相同像素尺寸下 live/full 一致性，以及切回彩色后的像素恢复；同时核对 25 款胶片、9 款相纸的 34 份 profile、产品署名、25 个自绘图标、CineStill Vulkan 着色器和 0.4.6 默认胶片顺序。Metal 结果不能替代 Android Vulkan / CPU 或实机验收。

## CineStill 800T 与高光余量

CineStill 800T 来自同一固定上游的 `resources_product/profiles/cinestill_800t.json`。它是已带完整授权信息的 Vision3 500T alias，只覆盖名称、静态照片用途和“无防光晕层”标记；脚本在生成 Android 目录时从 `derived_from` 继承其余 `info` 字段，没有复制或改写底片的测量数组。

“质感”页在选中 CineStill 800T 时，于“高光光晕”和“光晕增强”之间显示“高光余量”。范围为 0～8 EV，默认 4.0 EV；该参数只在 CineStill 的 `params()` 中出现，其他彩色胶片与黑白胶片不会接收隐藏值。

Android 图形补丁新增 `spk_highlight_headroom.comp`，按上游 Metal `nodes.metal` 的同一点处理逻辑实现：读取像素最亮通道，在两个 smoothstep 区间内计算权重，再对 RGB 使用相同增益，保持色彩比例不变。Vulkan pointwise 分块通过 push constant 的 base/origin 计帧内索引，避免大图分块后重复或错位。
