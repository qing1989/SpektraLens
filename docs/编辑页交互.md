## 2026-11-22 · 质感 / 漏光

- 「漏光」在「高光光晕」下方，标题右侧为「彩光 / 开卷」胶囊，下一行显示强度。默认彩光、0%。切换类型保留强度和种子。第一次调到非零并提交时生成照片的漏光种子。拖回 0% 或双击复位关闭效果，保留已有种子供再次开启。
- 「换一个」是滑块下方的整行深灰胶囊，两端对齐调节行。每次点击在当前类型内生成新种子，保留当前强度。从 0% 点击会同时设为 50%。切换类型、换样和强度调整各进入一次撤销历史。照片记录、复制粘贴和「再编辑一张」沿用同一份参数，包含类型、强度与种子。
- 2026-11-22 起，彩光形状为全幅可分离雾层：随机选择左/右/上/下入光边和沿边中心，浓度从入光边向对边递减，入光边保留一个更亮的软核心。深色像素按 luma 衰减雾量，纯白高光不染色；135 片基不受亮度衰减限制，继续延续漏光。
- 2026-11-22 起，彩光强度按平方根响应映射到雾量：0% 关闭、100% 上限不变，低百分比比旧线性曲线更早出现可见雾。开卷仍沿用原曲线，切换类型不改强度和种子。
- 漏光在共享的 16 位照片处理阶段合成，位于调色之后。彩光为从随机一侧进入、覆盖整幅画面的暖色雾，入光边更亮，深色区域按亮度保留；开卷为带黄橙内缘的一侧奶白烧曝，黑白胶片下两种效果均为无色。135 黑色与暖色边框的片基延续同一光斑，齿孔、编号和日期随后绘制。白边和拍立得仅照片区域有漏光。主预览、首页显影图、不同尺寸的导出使用同一光斑。对比原图和胶片型号画廊的默认配方不含漏光。缺少类型字段的照片按彩光读取。

当前发布版本为 `0.4.6 / versionCode 25`。

## 参数滑块双击复位

- 在某一条滑轨或滑块上双击，恢复该参数的初始默认值；不影响其他参数，也不切换胶片。
- 默认值与普通导入时的初始化共用 `MainActivity.sliderDefault()`。曝光、HSL 等为 0，银盐颗粒/高光光晕/胶片反差/日期字号等为 1，暗角范围为 50，边框宽度为 6，底片编号为 36。
- 复位同步数值、滑块位置、无障碍数值及颜色分级关联轨道颜色，作为一次编辑进入撤销/重做历史，仅请求一次主预览显影。已经是默认值时不增加历史、不显影、不震动。
- 单击轨道等待系统双击时间窗口后才生效，防止双击的第一下先跳值。开始水平拖动后立即交给原生 SeekBar；竖直滚动、取消、多指触摸与第二下长按不识别为复位。
- 点击其他控件前先确认上一条已经完成的单击；禁用或销毁旧滑块时取消待处理手势，避免将延迟操作带入另一张照片或另一页。
- 复位使用系统触感；滑块不再叠加全局点击震动。无障碍服务可以使用「恢复默认值」操作，原生范围调节继续可用。
- 照片本身的双击缩放手势仍由 `PhotoView` 独立处理；照片单击用于开合参数面板。

| 当前状态 | 点击 | 结果 |
| --- | --- | --- |
| 面板展开 | 当前工具 | 收起面板，扩大照片区 |
| 面板展开 | 其他工具 | 切换工具，面板保持展开 |
| 面板收起 | 原工具 | 恢复原二级页签与滚动位置 |

- 照片单击先等待系统双击时间窗口，确认没有第二下后才切换面板；双击仍只负责缩放，不切换面板。
- 拖动、双指缩放、对比分界线拖动、长按和取消手势都不切换面板。点击其他控件、离开编辑页、旋转屏幕或更换照片会取消尚未确认的照片单击，旧手势不能作用到新页面。

- 横屏展开时仍采用原来的左右分栏；收起后照片使用全宽，导航移到下方。旋转屏幕后保留开合状态。
- 开合不重建当前参数面板、不修改编辑参数、不添加撤销记录、不重新显影。重新展开胶片画廊时只补尚未完成的可见缩略图，已缓存图片继续复用。
- 换一张照片后恢复面板展开；同一张照片返回首页再进入时保留开合状态。

## 面板与导航动效

- 竖排布局的面板开合使用原生 `ValueAnimator`，完整行程为 200ms 缓出；面板高度、顶距与照片区高度同步变化，导航位置固定。面板配合淡入淡出与最多 8dp 的轻微下移。
- 动画只裁切外层面板，内部 `ScrollView` 暂时保持完整高度；结束后恢复原有按权重布局。同一工具的二级页签、滚动位置和画廊 View 均保留。
- 快速反向点击从当前高度、透明度与位移接续，按剩余行程缩短时间（最短 80ms）。动画中换工具按最后一次点击展开目标面板，旧动画的结束回调不能覆盖新状态。
- 新选中的底部工具使用 140ms 的轻微淡入与缩放复原（0.96 → 1），没有弹跳。只切换展开的工具时，照片区高度不变。
- 横屏左右分栏与竖排之间直接完成重排，导航仍有选中反馈。旋转、窗口变化、换照片、返回首页和离开应用时结束当前过渡并清理透明度与位移；系统关闭动画时直接显示最终布局。
- 照片单击与底部工具共用同一套 200ms 开合动效。动效只改变 View 布局与绘制属性；复用照片位图，不调用 `resetZoom()` 或主预览显影。`PhotoView` 仍按新边界限制越界平移，缩放倍数与原图对比分界保持。

## 长按临时查看原图

- “对比原图”关闭时，在照片实际显示区域内单指按住至系统长按阈值，预览临时切换到原图；手指抬起仍停留在原图上时、取消手势或按钮点按时恢复显影图。
- 长按成立时调用系统 `HapticFeedbackConstants.LONG_PRESS`，沿用手机的触感开关和马达能力，不自定义振幅，不忽略系统设置。
- 长按后继续移动越过拖动阈值、出现第二根手指、更新预览位图、开启“对比原图”或离开编辑页时立即退出临时原图，避免旧手势覆盖新状态。
- “对比原图”开启时由分界线比较接管预览，长按不再覆盖当前比较画面；长按也不会在双击确认窗口后触发参数面板开合。
