# C 方案：轻盈浮层

日期：2026-11-04。按用户选定的 C 概念图统一现有 App，使用原生 Android 控件实现。设计参考图位于本地被 Git 忽略的 `generated_images/ui-concepts-2026-11-04-v1/C-floating.png`，不作为应用贴图。

## 共同视觉语言

黑色背景，炭灰 `#222225` 浮层，较亮的 `#2D2D32` 控件底色，橙色 `#FF7A1A` 用于主操作和选中状态。面板圆角 26dp、底部工具栏圆角 28dp，描边细而克制。统一无衬线字体、纯文字操作和系统触感反馈。参数面板不模糊或遮盖照片，也不需要额外的实时模糊渲染。

样式由 `AppStyle` 集中管理；点击、禁用与选中有独立状态。胶卷卡片显示项目独立绘制的 20 款立体胶卷，参见[图标映射](图标映射.md)。

橙色主操作按钮统一参考“导出照片”的胶囊形：圆角随按钮实际尺寸取短边的一半，首页导入、顶部导出和弹窗主操作具有相同的半圆端部。按下反馈遮罩与禁用态也共用这一轮廓。

弹窗主按钮统一为 44dp 高、至少两倍高度的宽度，短文字的“完成、应用、关闭”等也保持横向胶囊。操作区根据实际文字宽度排列；小屏或放大字体下放不进同一行时自动换行，并为完整操作区预留高度，所有按钮保持横向、文字完整且互不重叠。

## 编辑页

- 顶部缩短留白，“照片编辑”仍独立居中，导出动作位于右侧。
- 照片下方为同一行的照片选择、可用撤销/重做、适应画面与原图对比。文件名可长按“照片”查看，最近底片保留原有格式和文件大小。
- 参数面板左右各留 12dp，与下方独立工具栏分离；工具栏固定为胶片、调整、边框、质感。
- 宽而矮的横屏使用左右布局，左侧完整预览、右侧参数与工具栏，避免照片被挤成很小的缩略图；竖屏与常规折叠屏继续采用上下布局。
- 顶部把手支持点击和拖动展开/收起，调整面板高度受可用视口限制。工具栏始终独立，照片始终在面板上方；尺寸改变不写入编辑参数。
- 胶卷列表采用较小的图标与两行型号名称，选中以橙色细框和文字标记。调整组、胶片分类、相纸/印相入口使用同一套圆角文字标签。
- 滑杆保留白色胶囊、完整端点留白、语义渐变和右侧数值框。小屏缩短名称与数值栏的固定宽度，保留更多轨道空间。
- 数值栏关闭单行横向滚动后再自适应字号，确保大字号时数值与 EV、μm 等单位完整显示；弹窗按钮也按文字宽度减少无效占位。
- 处理进度使用暂态提示，不改变照片区域的尺寸，避免显影开始或完成时照片上下跳动；错误、超时或需要重试时保留可见提示。成功后的技术耗时与尺寸文字不常驻照片下方，处理诊断仍可从关于进入。

## 首页与图库

首页采用更简洁的 SpektraLens 标题与说明，保留自动背景动效；固定 240dp 的预览横幅按图片中心裁切。导入主按钮、最近照片卡片和空状态统一圆角、间距与字体。照片标题去扩展名，格式/大小仍在标题下方。

手机图库为带外边距的圆角浮层，保留三列正方形缩略图、相册切换、已导入、文件入口和系统单选器；小图增加适度间隔与圆角。首次权限、部分授权、拒绝后回退、缩略图并发和时间倒序逻辑不变。

## 弹窗与输入

相纸、边框、色彩区域、导出格式、导出成功、关于、许可和错误提示共用圆角深色弹窗。主操作、普通操作与禁用状态统一；输入框使用一致的深色圆角样式。

弹窗样式在首帧绘制前完成，避免先闪现系统默认按钮再切换样式；不占用调用方的 `onShow` 事件，因此题注输入的校验和自定义按钮监听继续有效。图库和编辑面板的把手也提供真正的点击动作与按钮无障碍角色。

## 功能与交付范围

胶片/相纸数据、显影计算、原图导出、参数复用、自动测光默认关闭、暂时隐藏裁切等既有行为保持。此次界面修改随 v0.3.3 私人安装包交付，历史交付文件保持原字节，GitHub 上传仍暂缓。

专项测试覆盖面板展开/收起的布局边界、题注输入校验与取消、导入后清理对比选中态，并沿用图库、端点、胶片图标、导出和系统触感检查。具体测试结果与多尺寸截图检查见[验证记录](验证记录.md)。
