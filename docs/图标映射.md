# SpektraLens 胶卷图标

当前 20 个配置统一使用项目原创的 Canisters 01 系列。每款图标按图库目录中的型号、感光度和推片信息绘制。卷芯凹口、金属压边、纸面弧度和带齿孔的片头由同一组几何路径构成。标签保留型号和大号感光度，轮廓尺寸适配编辑器的 45dp 高胶卷卡片。负片使用单色带，反转片使用双线，电影卷使用帧格。配色为本应用设计。

Android 绘制源位于 `FilmCanisterArtwork.java`，每款标签的定义位于 `android/app/src/main/assets/film_icons/manifest.json`。绘制代码、定义与渲染图使用 GPL-3.0-or-later。可通过 `FilmArtworkInstrumentedTest` 在 Android 重绘全套透明 PNG 和总览。
