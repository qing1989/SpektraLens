# 公开版图标 · v0.3.2

公开 GitHub 源码和公开构建不包含 11 张 GRLife 原始 PNG。公开版的 20 款胶片全部由 `FilmLabelArtwork.createPublic` 独立绘制文字标签，保留统一外壳、片头、型号、感光度和推片标记，不需要下载原图。代码及标签定义按 GPL-3.0-or-later 提供；品牌和型号仅用于识别模拟材料，不表示官方合作。

以下 v0.2.4 映射表记录本地授权版本的历史来源，不表示相应 PNG 已公开或授权公众下载。原图缺失时整个图库自动使用公开标签；有本地原图时，`-PpublicBuild=true` 仍会明确排除它们。

# 胶卷图标映射 · v0.2.4

20 款配置现在全部使用同一套胶卷外壳、片头、金属边缘和选中标记。11 张授权 GRLife 原始 PNG 覆盖 13 个配置，保持原始字节及 SHA-256；其余 7 款采用本项目补绘的矢量标签。Portra 800 推片仍使用原图，并独立显示 +1 / +2。

补绘沿用已有标签的透明留白、圆角色块、左侧窄条与竖排型号。标签在 120 × 120 逻辑坐标绘制，在 Android 上以 480 × 480 渲染后放入同一外壳。绘制源为 `FilmLabelArtwork.java`；每款文字和配色位于 `assets/film_icons/manifest.json`，不依赖系统联网或缺省图案。
